# Spec Delta

## ADDED Requirements

### Requirement: 扩展设置值的实时推送

当扩展在运行期写入自己的设置项时，宿主 SHALL 把该变化推送给**正在显示该扩展设置项**的系统扩展页面，
使只读状态字段（如迁移状态）与进度字段（如迁移进度）无需用户手动刷新即可更新。
推送 MUST 是增量消息（只带变化的扩展 id 与键值），不得重发整份页面上下文；宿主 MUST NOT 依赖页面的轮询。

#### Scenario: 迁移进度实时前进

- **WHEN** 网页应用扩展在迁移过程中把 `webapp.migrationProgress` 从 `3` 改写到 `4`，且用户正停在「设置 → 扩展 → 网页应用」
- **THEN** 宿主把这条变化推给设置页，进度条从 3/N 前进到 4/N，页面其他字段不重绘、不闪烁

#### Scenario: 迁移结束后进度清空、状态变短标签

- **WHEN** webapp 把 `migrationProgress` 清空并把 `migrationStatus` 写成「已完成」
- **THEN** 设置页的进度条消失，同一行显示「已完成」

#### Scenario: 页面不在该分区时不打扰

- **WHEN** 用户当前停在「设置 → 网络」，而 webapp 更新了迁移进度
- **THEN** 宿主不向该页面推送这条变化（等到用户切回该分区时以最新快照为准）

#### Scenario: 未升级的页面不受影响

- **WHEN** 某个旧版本系统扩展页不认识这条增量消息
- **THEN** 它按既有方式工作（整份快照 + 动作后刷新），不报错、不空白
